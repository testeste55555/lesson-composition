# lesson-composition

PreA1〜A2を中心に、学習者の「発話・行動」から授業形態を検討するチェックツールです。

## 公開構成

- `/` : PC版／スマホ版の入口
- `/pc/` : PC版
- `/mobile/` : スマホ版（PWA・オフラインキャッシュ対応）

PC版・スマホ版は同じ判定エンジンを使用します。

## V2：2つのモード

### 1. いまある授業を見直す

既存授業ファイルを手掛かりにしながら、教師のチェックで実態を補正して判定します。

ブラウザ内で内容抽出を試みる形式：

- PPTX
- DOCX
- XLSX
- ZIP（内部のTXT / CSV / JSON / HTML / XML等）
- HTML / TXT / Markdown / CSV / JSON

ZIP内がPowerPoint / Word / ExcelのOOXML構造になっている場合は、拡張子が`.zip`でも内部構造から自動判別して本文抽出を試みます。PowerPoint教材では、漢字表記だけでなく、ひらがな中心の指示・活動表現も手掛かりにします。

教材に単に「ききます」「もちます」「しゃしん」等の語彙が載っているだけで、音声・身体活動・画像機能があるとは判定しません。また、対象レベルとしてA1/A2/N4等が書かれているだけで「難易度切替あり」とは判定しません。

ファイル解析は3段階で扱います。

1. **ファイルで直接確認できたもの**：埋込画像・埋込音声・実際の多言語本文など、ファイル構造や実データから確認できる項目は「元授業にすでにあるもの」へ自動プリセットします。教師は必要なら修正できます。
2. **教師確認が必要な候補**：ペア・発話・身体活動・反復など、教材本文に手掛かりはあるが実際の授業運用までは確定できない項目はHuman Gateに提示し、教師が承認した場合だけ判定へ入れます。
3. **ファイルだけでは判定しないもの**：教師の発話量、実際の待ち時間、実際の反復回数など、授業運用に依存する項目は自動判定しません。

活動ブロック候補は説明用で、得点へ直接入れません。

PDFは現時点では本文自動抽出を行わず、教師チェックを中心に判定します。

既存授業モードでは、結果に「残す／変える／追加／削る」を表示します。

### 2. これから授業を作る

ファイルを使わず、学習者・学習目標・教室条件・運営方針をタップして授業の骨格を決めます。

## 共通の判定5軸

1. 学習活動
2. 参加形態
3. 教材媒体
4. 補助機能
5. 授業内の役割

PowerPointかHTMLかの二択ではなく、たとえば「身体反応・TPR × 全体一斉」「主媒体は実物、補助に音声」のように別軸で組み合わせます。

## 汎用性RED TEAM

特定教材へ過学習しないよう、`.github/workflows/genericity-red-team.yml` で回帰テストを実行します。

主な検査例：

- 語彙として「ききます」があるだけで音声機能としない
- 語彙として「もちます」があるだけで身体活動としない
- 「A1レベル」と書いてあるだけで難易度切替としない
- 相手の話を聞く活動を音声教材と混同しない
- URLや英字メタデータを多言語支援と混同しない
- 推定候補を教師承認前に得点へ入れない
- 視覚提示と選択・判断活動を同一視しない

受入テスト用の個別教材名・個別語彙を、そのまま本番のカテゴリや判定ルールへ固定しないことを原則とします。

## プライバシー最優先

このリポジトリは公開リポジトリです。実際の授業ファイル・学習者情報・個人情報はコミットしません。

- 選択した授業ファイルはブラウザ内だけで解析する
- ファイル本文を外部APIやGitHubへ送信しない
- 解析後、本文や元ファイル名を判定データとして保持しない
- 外部解析API・アクセス解析・外部スクリプトを原則使用しない
- Content Security Policy で通信先を原則同一オリジンへ制限する
- `.gitignore` でOffice/PDF/ZIP、個人情報を含み得る画像・音声・動画、秘密情報、ローカル入力を除外する
- 公開が必要な媒体は、人が内容確認したものだけ `assets/public/` に置く

詳細は [`PRIVACY.md`](./PRIVACY.md) を参照してください。

> 注意：`.gitignore` は未追跡ファイルの誤コミット防止です。一度Git履歴へ入った個人情報・秘密情報は、最新コミットから削除するだけでは履歴に残ります。

## 設計原則

- PreA1〜A2では、教材操作より「見る・聞く → 動く・言う」を優先する
- 授業全体を一つの媒体・活動形態に固定しない
- 既存授業は活動ブロック単位で改善を考える
- 多言語は常時併記ではなく、必要時表示を基本とする
- 自動解析だけで授業意図を断定せず、教師の確認を残す
